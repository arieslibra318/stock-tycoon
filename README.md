# 證券大亨 Stock Tycoon

1980 年代末的台北，股市一天比一天熱。你是剛北上的年輕人阿德，帶著 200 萬本金在一顆小小的城市星球上跑街：去證券行看盤下單、在茶藝館和居酒屋打探消息、分辨誰的明牌比較準，一路從菜籃族爬到證券大亨。

**線上遊玩：** https://arieslibra318.github.io/stock-tycoon/

## 一天怎麼過

| 時間 | 時段 | 可以做的事 |
| --- | --- | --- |
| 06:00 | 清晨 | 看早報：昨晚美股收盤、國際頭條 |
| 08:00 | 盤前 | 日本、韓國開盤，街上打探消息 |
| 09:00–13:30 | 盤中 | 到證券行看盤下單（現股、融資、融券） |
| 13:30–18:00 | 盤後 | 驗證消息、跑街、買東西 |
| 18:00–23:00 | 夜晚 | 居酒屋開門，大戶喝醉了什麼都講 |

一季 40 個交易日，季末結算排名，並和同期大盤比較，接著進入下一季。故事共 5 季（200 個交易日），第 5 季結束時迎來結局：

| 結局 | 條件 |
| --- | --- |
| 成功「台北股市傳奇」 | 第 5 季結束時總資產 1,000 萬以上；中途當上證券大亨（5,000 萬）會提早迎來「證券大亨誕生」 |
| 普通「平凡的幸福」 | 第 5 季結束時總資產介於 200 萬和 1,000 萬之間 |
| 失敗「泡沫之後」 | 第 5 季結束時總資產低於本金 200 萬；中途跌破 30 萬會提早迎來「斷頭的那一天」 |

每個結局都有自己的動畫和配樂，最後列出五季的資產與大盤對照。結局之後可以繼續自由遊玩，或重新開始。

行情依 1987～1989 年的台股多頭校準：當時加權指數一年漲 88%～125%，最熱的 1988 年 6 到 8 月兩個月漲了約 4 成。遊戲裡大盤一季的中位數約 +8%；個股波動比大盤大得多，明牌也多半出在隔天真的會大漲大跌的股票上。依模擬，用心打聽、跟著準的人操作，一季賺到五成（散戶門檻 300 萬）的機會約一半；敢用融資的高手，一季翻倍的機會約五成。

## 操作

| 操作 | 鍵盤 |
| --- | --- |
| 移動 | WASD／方向鍵（Shift 快跑） |
| 說話、互動 | E |
| 看盤下單 | K |
| 消息本 | N |
| 暫停 | P |
| 快轉到下一個時段 | T |
| 城市地圖 | M |
| 指南 | H |
| 暫存目前進度 | Q |
| 存檔與讀檔 | O |

手機用左下的搖桿移動、「互動」按鈕說話，其餘功能在右上角的按鈕列。

遊戲不會自動存檔。按 Q 留一個暫存點，或在存檔畫面存到 3 個存檔格之一；存檔只在這台裝置的這個瀏覽器裡，換裝置可以用「存檔碼」。

## 遊戲內容

- **12 檔虛構股票**，分成價值股、循環股、成長股：寶島金融、島嶼電信、寶島食品、大稻埕紡織、淡水塑化、南港鋼鐵、基港航運、城中營造、新竹微電、福爾摩沙晶圓、雲頂電腦、南港生技。
- **改編自歷史的市場事件**，每季隨機排列：1987 年黑色星期一、1988 年證所稅風暴、1989～1990 年金融股狂潮、1990 年波斯灣危機、1979～1981 年伏克爾升息與美債風暴、1995～1996 年台海飛彈危機、1997 年亞洲金融風暴、2023～2024 年 AI 浪潮等；也會隨機出現縮小或放寬漲跌幅限制的政策事件。遊戲內「消息本 → 歷史小百科」會說明每個事件改編自哪一段歷史。
- **走勢圖**：看盤畫面可以看大盤、個股或自己總資產的「本季累積」日線，以及「今日分時」；圖上會標出重大事件和你的持股均價。
- **等級**：跑單小弟 → 散戶（300 萬）→ 中實戶（600 萬）→ 大戶（1,500 萬）→ 證券大亨（5,000 萬）。資產會帶到下一季，通常要好幾季才當得上大亨。
- **消息系統**：每個人的消息準確度不同，而且不會告訴你，只能從消息本的戰績慢慢推敲。
- **天氣**：颱風會停止交易，雨天的人氣比較差。在 GitHub Pages 上可以切換成台北的真實天氣。
- **彩蛋**：城裡藏了 10 個，路上的行人偶爾會透露線索。

- 3D 使用 [three.js r128](https://threejs.org/)（MIT 授權，從 cdnjs 載入）。
