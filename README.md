# 證券大亨 Stock Tycoon

1980 年代末的台北，股市一天比一天熱。你是剛北上的年輕人阿德，帶著 200 萬本金在一顆小小的城市星球上跑街：去證券行看盤下單、在茶藝館和居酒屋打探消息、分辨誰的明牌比較準，一路從菜籃族爬到證券大亨。

**線上遊玩：** https://arieslibra318.github.io/stock-tycoon/

## 一天怎麼過

| 時間 | 時段 | 可以做的事 |
| --- | --- | --- |
| 06:00 | 清晨 | 看早報：昨晚美股收盤、國際頭條 |
| 08:00 | 盤前 | 日本、韓國開盤，街上打探消息 |
| 09:00–13:30 | 盤中 | 到證券行看盤下單（現股、融資、融券） |
| 13:30–18:00 | 盤後 | 驗證消息、跑街、買東西 |
| 18:00–23:00 | 夜晚 | 居酒屋開門，大戶喝醉了什麼都講 |

每季 20 個交易日、代表一年。開新局時選 **6 季（1985–1990）** 或 **12 季（1985–1996）**，開季指數依前一年底台股的收盤水準。1990 年那一季前半段衝向萬點，央行緊縮後泡沫破裂；遊戲後半段（季數過半之後）行情偏空，大約六到七成的日子下跌。季末結算排名並和同期大盤比較，最後一季結束時迎來結局：

| 結局 | 條件 |
| --- | --- |
| 成功「台北股市傳奇」 | 最後一季結束時總資產達標：6 季局 500 萬、12 季局 1,000 萬；中途當上證券大亨（3,000 萬）會提早迎來「證券大亨誕生」 |
| 普通「平凡的幸福」 | 介於本金和成功門檻之間 |
| 失敗「泡沫之後」 | 最後一季結束時總資產低於本金 200 萬；中途跌破 30 萬會提早迎來「斷頭的那一天」 |

每個結局都有自己的動畫和配樂，最後列出每一季的資產與大盤對照。結局之後可以繼續自由遊玩，或重新開始。

行情依 1987～1989 年的台股多頭校準：當時加權指數一年漲 88%～125%，最熱的 1988 年 6 到 8 月兩個月漲了約 4 成。遊戲裡大盤一季的中位數約 +8%；個股波動比大盤大得多，明牌也多半出在隔天真的會大漲大跌的股票上。依模擬，用心打聽、跟著準的人操作，第一季就升上散戶（250 萬）的機會約七成；敢用融資的高手，一季翻倍的機會約五成。

## 操作

| 操作 | 鍵盤 |
| --- | --- |
| 移動 | WASD／方向鍵（Shift 快跑） |
| 說話、互動 | E |
| 看盤下單 | K |
| 消息本 | N |
| 暫停 | P |
| 快轉到下一個時段 | T |
| 城市地圖 | M |
| 指南 | H |
| 暫存目前進度 | Q |
| 存檔與讀檔 | O |

手機用左下的搖桿移動、「互動」按鈕說話。上方只留暫停、快轉、消息本、看盤，其他功能（城市地圖、聲音、存檔、說明）收在「⋯」選單裡；任務提示可以點標題收合。看盤畫面在手機上會改成卡片排版，買賣按鈕直接放在每一檔股票下面，走勢圖預設收起。

遊戲不會自動存檔。按 Q 留一個暫存點，或在存檔畫面存到 3 個存檔格之一；存檔只在這台裝置的這個瀏覽器裡，換裝置可以用「存檔碼」。

## 遊戲內容

- **28 檔虛構上市公司**，金融、食品、塑化、航運、營建、電子、半導體、伺服器、生技等族群各有好幾檔，看盤畫面可以依族群篩選。
- **新股上市與下市**：每季有 1–2 檔新股掛牌，掛牌前 5 天可以在證券行申購抽籤（中籤率約 15%），新股掛牌頭兩天常常漲停；經營不善的公司會先打入全額交割股（不能融資融券）、連續跌停，最後一天收盤後終止上市，手上的部位以最後收盤價清算。
- **融資券追繳**：收盤時維持率低於 130%，營業員會發出追繳令，兩天內要補繳到 166% 或自己賣掉，否則強制平倉；跌破 100% 會立刻斷頭。
- **改編自歷史的市場事件**，每季隨機排列：1987 年黑色星期一、1988 年證所稅風暴、1989～1990 年金融股狂潮、1990 年波斯灣危機、1979～1981 年伏克爾升息與美債風暴、1995～1996 年台海飛彈危機、1997 年亞洲金融風暴、2023～2024 年 AI 浪潮，以及疫情爆發、全球塞港、歐陸戰爭等；也會隨機出現縮小或放寬漲跌幅限制的政策事件。遊戲內「消息本 → 歷史小百科」會說明每個事件改編自哪一段歷史。
- **走勢圖**：看盤畫面可以看大盤、個股或自己總資產的「本季累積」日線，以及「今日分時」；圖上會標出重大事件和你的持股均價。
- **等級**：跑單小弟 → 散戶（250 萬）→ 中實戶（500 萬）→ 大戶（1,000 萬）→ 證券大亨（3,000 萬）。資產會帶到下一季。
- **下單張數**：每次可以下 1、5、10 張，或用 ¼、½、全部的資金；賣出時是持股的同樣比例。
- **賺賠回饋**：持股漲停時證券行前的人群歡呼、畫面泛起金光；融資或融券接近斷頭線時，營業員小美會打電話示警。
- **街頭反應**：大漲日行人多、走得快，大跌日街上冷清；路人會聊今天的行情，大漲大跌的日子報攤會喊「號外」。
- **交情與消息體質**：每個人的消息體質開局時隨機決定、玩家看不到——很準的人（交情越好越準，最高八、九成）、像丟銅板的人（一直五成左右）、反指標（大概兩成會對）。交情靠聊天和請客累積，太久沒去找會變淡，頭上會顯示 ♥。
- **不定期出現的角色**：研究部分析師陳博士（族群三天走勢）、投顧老師「股市明燈」、大學林教授（總體事件）、晚上才出現的官員司機老蔡（政策、下市、新股的內線）。早報的「今日動態」會說誰今天會出現。
- **小地圖與步數**：右下角小地圖會標出場所、還沒聊過的人和目的地；畫面上方記錄今天走了幾步，一天走滿一萬步有小驚喜。
- **新手教學**：第一天營業員小美帶你走一遍：打聽消息 → 下單 → 看收盤 → 查消息本，也可以跳過。
- **消息系統**：每個人的消息準確度不同，而且不會告訴你，只能從消息本的戰績慢慢推敲；分析師的族群報告三天後驗證。
- **天氣**：颱風會停止交易，雨天的人氣比較差。在 GitHub Pages 上可以切換成台北的真實天氣。
- **彩蛋**：城裡藏了 10 個，路上的行人偶爾會透露線索。
